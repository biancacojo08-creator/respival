# Biblioteca de animații

Toate clipurile animate generate cu AI, păstrate ca să le refolosim în alte videouri. Fiecare clip are lângă el cadrul de start, adică poza din care a fost animat.

- `clipuri/`: animațiile (.mp4), la rezoluția originală
- `cadre-start/`: poza de start a fiecărui clip (.jpg)

Când adăugăm un clip nou, îl punem aici și completăm tabelul.

| Clip | Ce se vede | Durată / format | Produs vizibil | Model, cost | Folosit în |
|---|---|---|---|---|---|
