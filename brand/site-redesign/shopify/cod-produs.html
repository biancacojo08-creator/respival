Secțiunea „Novensa – Pagină produs”

1. Adaugă codul

  1. Apasă Copiază tot codul.
  2. Shopify → tema Copy of Craft → Edit code → Sections → Add a new section → nume novensa-product.
  3. În fișierul nou: Cmd+A, apoi Cmd+V. Ultima linie trebuie să fie {% endschema %} (linia 275). Save.

2. Fă un șablon doar pentru un produs

  1. Customize → sus, din lista de pagini alege Products → Create template → nume premium, bazat pe Default product → Create.
  2. În șablonul premium: ascunde secțiunea Product information (iconița cu ochi) → Add section → Novensa – Pagină produs → trage-o sus. Save.
  3. În Products (din admin), deschide produsul ales → în dreapta, la Theme template, alege premium → Save.
  4. Deschide pagina produsului ca să vezi rezultatul. Celelalte produse rămân neschimbate.
